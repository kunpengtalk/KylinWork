从任务到文件，一站式全流程

它不是聊天机器人——会规划、会动手、会交付，还会自己安排重复的工作。六件每天都用得上的事，一次说清。

任务全流程执行

自然语言 → 规划 → 工具循环 → 交付文件，每一步实时可见。Ask / Plan / Goal / Craft 四种模式：只问答、只出计划、目标验收、完整执行，输入框旁一键切换。

交付真文件

PPT / Word / Excel / 网页 / 图片 / 视频真实写入磁盘，用 Office 就能继续编辑。声称写了文件却不在磁盘上，会被拦下来重做——不是聊天记录。

多模型自由切换

DeepSeek / 通义 Qwen / 智谱 GLM / Kimi / OpenRouter / Ollama 本地模型，界面点一下就切、不用重启；每个对话还可以单独指定自己的模型。

定时任务

cron 到点自动执行，结果推到飞书 / 微信 / QQ。合上盖子睡过头了会自动补跑（只补最近一次、最多 24 小时），同一个任务绝不叠跑。

多端远程派活

飞书、QQ、微信、企业微信、钉钉，在外发条消息就能指挥这台电脑，干完把文件推回聊天。所有渠道汇成一条对话历史，重启不丢。

数据留在本机

自托管，会话、文件、API Key 全在自己机器上；默认只监听 127.0.0.1，不主动外发。备份就是把整个数据文件夹拷走。

不止于此，把 Agent 用顺手的小事

评测、账本、记忆、宠物——这些不显眼的能力，是用久了才会喜欢上的细节。

智能体评测

把整个 agent 当黑盒考：15 道分层任务，pass@1 均值看能不能、k 次全过看稳不稳。可设为基线，之后每轮自动逐题对比、退步点名。

模型健康账本

每次任务按模型记成败（滚动近 20 次），选模型菜单里直接看「近 N 次任务 X 成」，连挂 ≥2 次标红——坏的渠道一眼看清，不再盲猜。

双层记忆

手写区全局共享、界面直接编辑；条目区由 agent 自己用 remember 记录，按账号隔离、超量丢最旧。越用越了解你的习惯。

桌面宠物

桌角一只透明小挂件，实时显示 agent 在干什么：跳起来 + 通知 = 有问题要问你，撒花 = 完成，掉汗 = 出错。还能用你的照片现场做一只。
